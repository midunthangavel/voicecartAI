Single-screen React Native app bootstrapped by `App.js`, which wraps the UI in a `VoiceSessionProvider` from `src/context/VoiceSessionContext.jsx`. The context layer is the central orchestrator: it owns all call/session state (`callState`, `transcript`, `cartItems`, `isRecording`, `isAiSpeaking`, `audioLevel`, `latencyMs`, `activeLanguage`, catalog/cart modals) and wires three service modules — `voiceSocketService.js` (a singleton `VoiceSocketService` wrapping native `WebSocket` with an event emitter API for `ai_response`, `stt_transcript`, `order_confirmed`, `close`, `error`), `audioManager.js` (recording via `expo-av` and TTS via `expo-speech`), and `apiService.js` (HTTP fetch for menu catalog and server health ping). Components under `src/components/` are pure presentational pieces grouped by feature area: `common` (HeaderBar, ShortcutsBar), `controls` (ConnectButton, ControlBar, DTMFKeypadModal), `conversation` (ConversationPanel, MessageBubble, ThinkingIndicator, FunctionCallBadge), `visualizers` (CircularWaveform, VoiceVisualizer), and `commerce` (MenuCatalogModal, LiveCartDrawer). Dependency direction is strictly one-way: components consume state/actions via the `useVoiceSession()` hook; the context calls services; services never import components. A shared `src/theme/colors.js` provides the color palette consumed across components.
