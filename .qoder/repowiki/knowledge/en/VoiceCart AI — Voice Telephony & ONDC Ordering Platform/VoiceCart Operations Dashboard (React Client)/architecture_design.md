Single-page React app bootstrapped via `src/main.jsx` into a root element, with `App.jsx` acting as the top-level router that switches between views (`simulator`, `calls`, `orders`, `catalog`, `analytics`, `enterprise`, `mobile-call`) based on local state and URL path. UI is organized as flat presentational components under `src/components/` (Sidebar, VoiceSimulator, LiveCallMonitor, OrderDispatch, CatalogManager, VoiceAnalytics, EnterpriseConsole, MobileCallView, LoginModal) driven by shared state from custom hooks in `src/hooks/`. The `services/apiClient.js` module centralizes all HTTP communication, providing `apiFetch` with automatic Bearer token injection, 401-driven refresh-token rotation, and session persistence in `localStorage` keys (`voicecart_token`, `voicecart_refresh_token`, `voicecart_user`). Real-time data flows through `useDashboardWs.js`, which opens a WebSocket to `/dashboard-ws` using a one-time ticket or access token, buffers events, and polls `/api/v1/stats` every 5 seconds. Vite dev server proxies `/api`, `/voice`, `/pin`, `/web-stream`, `/dashboard-ws` to `localhost:3001`; production builds are SPA-rewritten via `vercel.json` to serve `index.html` for client-side routing.
