The root acts as a monorepo-style orchestrator that composes four independent child services around a common runtime contract. The `package.json` top-level scripts (`dev`, `dev:server`, `dev:client`, `mobile`, `test`, `build`) delegate to each child via `npm --prefix <child>` so developers can launch the full stack or individual components from one place. Production deployment is defined by a multi-stage `Dockerfile` that builds the React client in a separate stage and serves its static assets from the Node.js Express server on port 3001, while `docker-compose.yml` spins up the server alongside Redis (for job queues) with health checks against `/api/engine-status`. The `vercel.json` rewrites route all frontend traffic to `index.html` for SPA routing when the client is deployed separately. The security suite is invoked through dedicated `sec:*` scripts that target any combination of server/client/mobile, enabling automated audits and sandboxed pentests against the running stack.
