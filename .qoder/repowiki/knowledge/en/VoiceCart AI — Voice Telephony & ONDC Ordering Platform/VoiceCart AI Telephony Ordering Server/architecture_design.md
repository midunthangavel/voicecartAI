Composition root in `server.js` boots a Node HTTP server, initializes SQLite via `src/db.js`, creates the Express app (`src/app.js`) which wires security (helmet, cors), rate limiting, correlation-id middleware, health probes, and mounts route groups under `/api/v1` and `/api`. A separate WebSocket coordinator (`src/websocket/wsServer.js`) upgrades connections on `/media-stream`, `/web-stream`, `/dashboard-ws`, `/exotel-stream` with per-path ticket/token auth and dispatches to dedicated handlers. Business logic is layered: controllers (`src/controllers/*`) handle HTTP requests, services (`src/services/*`) encapsulate external integrations (LLM, STT/TTS, Exotel, WhatsApp, ONDC, payments), domain state machines live under `src/domain/{orders,catalog,dispatch,payments}`, and data access goes through `src/db.js` plus migrations in `src/db/migrations/*.sql` run by `migrationRunner.js`. Persistence is SQLite with an idempotency store, Redis-backed session store, and a custom database-backed durable job queue (`src/queue/jobQueue.js`) used by background workers (`src/workers/*`). Cross-cutting concerns are centralized in `src/middleware/*` (auth, RBAC, validation, idempotency, error handling) and schemas in `src/schemas/*` validate all inputs via Zod.
